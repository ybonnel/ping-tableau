Classement intégral

Personne ne s’arrête à sa première défaite.

Les gagnants poursuivent vers le titre. Les perdants rejoignent les tableaux de classement, puis continuent à jouer pour départager toutes les places.

Si le nombre d’équipes ne remplit pas le tableau, des exemptions sont attribuées automatiquement.

2. Jouez et notez les résultats

Saisissez le score global de chaque rencontre (manches ou parties gagnées). Les équipes avancent automatiquement.

Sauvegarde automatique dans ce navigateur. Exportez un fichier pour conserver une copie ou changer d’appareil. Pas de synchronisation entre téléphones.

Les tableaux

V = victoire, D = défaite dans les parcours. Faites défiler les tours horizontalement. Une correction annule les résultats qui en dépendent.
